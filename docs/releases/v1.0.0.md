# AstraMind v1.0.0 — Platform API v1

Release date: 2026-09-23

## Overview

AstraMind v1.0.0 establishes the first stable, domain-neutral Platform API. It exposes existing AstraMind engine capabilities through a versioned HTTP interface for application integration.

## Platform API

Base path:

`/api/v1`

### Endpoints

| Method | Endpoint | Purpose |
|---|---|---|
| GET | `/api/v1/health` | Liveness |
| GET | `/api/v1/status` | Provider/model status |
| GET | `/api/v1/version` | Version |
| GET | `/api/v1/providers` | Active provider |
| GET | `/api/v1/models` | Active model |
| POST | `/api/v1/chat` | Chat |
| POST | `/api/v1/chat/stream` | SSE streaming |
| GET | `/api/v1/documents` | List documents |
| POST | `/api/v1/documents` | Import documents |
| GET | `/api/v1/documents/{id}` | Get document |
| DELETE | `/api/v1/documents/{id}` | Delete document |
| POST | `/api/v1/documents/{id}/analyze` | Analyze document |
| POST | `/api/v1/embeddings` | Generate embedding |
| POST | `/api/v1/search` | Keyword/semantic search |

## Architecture

The API reuses the existing AstraMind:

- ProviderManager
- Knowledge Base
- document import/chunking/storage
- embedding infrastructure
- keyword and semantic search

The legacy local web API remains unchanged.

The Platform API is intentionally domain-neutral so applications such as SkillSifter can consume AstraMind without embedding domain-specific logic into the platform.

## Reliability and Compatibility

- Structured JSON errors
- `X-Request-ID` propagation/generation
- SSE token/done/error events
- Existing CLI, provider, Knowledge Base, and legacy web functionality preserved
- API-specific tests added
- CI and lint validation completed before merge

## Deliberate Non-Goals

The v1 release does not introduce:

- Agents
- Tool orchestration
- API-key management
- RBAC
- Vector databases
- Reranking
- Distributed deployment
- SDKs
- Advanced observability

These remain future work only when a concrete application requirement justifies them.
